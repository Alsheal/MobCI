Результаты сборки

Jenkins выполняет автоматизированный Pipeline. После успешного прохождения тестов Android-приложение собирается в APK-файл и сохраняется как артефакт сборки.

Для просмотра результатов, журналов и скачивания APK открой Jenkins.

Инфраструктура проекта

Система развёрнута с использованием Docker Swarm.

  • Nginx — обратный прокси-сервер.
  • Frontend — веб-интерфейс MobCI.
  • Backend — Node.js и Express.
  • MySQL — база данных.
  • Adminer — управление базой данных.
  • Jenkins — автоматизация CI/CD Pipeline.
  • Gradle и Android SDK — тестирование и сборка APK.

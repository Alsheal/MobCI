Инфраструктура проекта

Проект использует контейнеризированную архитектуру Docker.

  • Proxy — Nginx, обработка входящих HTTP-запросов.
  • Frontend — веб-интерфейс системы.
  • Backend — Node.js и Express.
  • DB — MySQL, хранение информации о запусках.
  • Cache — Redis, кэширование данных.
  • Adminer — управление базой данных.
Демонстрационный стенд показывает инфраструктуру CI/CD, автоматизированное тестирование backend и учёт запусков мобильных платформ. Реальная сборка APK, AAB или IPA требует исходного кода мобильного приложения и соответствующей среды сборки. В данном проекте она не выполняется.
